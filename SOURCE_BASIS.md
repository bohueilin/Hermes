# Source Basis

This Phase 6 pack was synthesized from the supplied Hermes design-review brief, comprehensive build plan, completed Codex handoff, project brief, and README.

The pack preserves the source framing that Hermes is simulation-only, that hard invariants are non-compensatory, that candidate/permitted/executed actions remain distinct, that stored verification does not rerun the simulator, and that current local hashing is tamper-evident rather than authenticated.

Codex must inspect the actual repository before relying on historical branch, commit, test-count, artifact-name, or schema claims.
