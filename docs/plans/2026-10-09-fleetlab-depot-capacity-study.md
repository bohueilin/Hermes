**Engine (`depot-capacity.js`)** `simulateCapacity(input, rule, {propose=null, shouldCancel=()=>false}={})`:
- Validate; `q = time_quantum_ms/1000`; slot bytes `uplink_bytes_s*q`; per-vehicle slot cap `vehicle_uplink_cap_bytes_s*q`; site slot joules `site_power_j_s*q`; port slot joules `port_cap_j_s*q`.
- State per vehicle `{present:false,bytes:0,joules:0,post:0,done:{},ready:null,port:null}`; `holder` for serial upload rules; `ports` map port index (1..2) → vehicle id.
- Boundary `settle(time)` in this order: (a) completions for present vehicles: upload when `bytes===upload_bytes`, charge when `joules===energy_j` (release its port), post when `post===post_s` and upload done; (b) arrivals: vehicles with `arrival_s===time` become present with `event('arrival')`; a zero-energy arrival records `complete charge` at arrival (as NF-02 does), a zero-byte arrival records `complete upload` at arrival; (c) readiness when all three done and not yet ready; (d) `deadline` events for `deadline_s===time`.
- Allocation per slot k: eligible = present with upload incomplete. Observation to `propose` (frozen): `{slot_index,time_s,time_quantum_ms,slot_bytes,uplink_bytes_s,vehicle_cap_bytes:capBytes,eligible:[{id,arrival_s,deadline_s,remaining_bytes}]}` (no future wave, no energy fields). Default grants: equal share = floor(slotBytes/n) each plus remainder rotated by `(k+j)%n` over eligible in arrival then ID order, each capped at the vehicle cap (if the cap binds, give the leftover to nobody; record it as unused capacity by simply not granting); serial rules keep the holder while it has work, else pick by (deadline | remaining bytes | nothing) then arrival then ID, grant `min(slotBytes,capBytes)`.
- Policy validation as NF-02 (`cohortObject(grants, eligibleIds, false)`, nonnegative safe integers, sum ≤ slot bytes, each ≤ vehicle cap, progress when possible) → `POLICY_ERROR` diagnostics and `failed` status.
- Charging per slot: queue = present with energy incomplete and no port, ordered by arrival then ID; fill free ports in order; occupied count n → per-port grant `min(portSlotJ, siteSlotJ/n)`; this must be an integer (validate at scenario build: `site_power_j_s*q/n` integer for n in 1..2); useful = `min(grant, remaining)`; record `charge[id]=useful/q`, `power[id]=grant`, `power_unused[id]=grant-useful`, `ports[id]=portIndex`.
- Upload useful = `min(grant, remaining)`; `upload[id]=useful/q`, `grants`, `unused`. Post progresses by `q` when upload done and post not done.
- Push `intervals[k]={id:k,start_s:time,end_s:time+q,upload,grants,unused,charge,power,power_unused,ports}`; `time+=q`; `settle(time)`; loop while `time<horizon_s` and not cancelled.
- Return record `{versions:{...CAPACITY_VERSIONS},...FLOW_TRUST,scenario,rule,execution_status,policy_status,end_s,events,intervals,diagnostics,totals:{upload_bytes,energy_j}}`.
- `export function runCapacityCell({regime,treatment,rule,time_quantum_ms})` → `{scenario,record,verification,digest}`; `export function* capacityCellSteps(cells, runtime)` yielding each cell for the browser loader.
